# SAP-1 Architecture based 8-bit Computer Design and Implementation
An 8-bit SAP-1 computer designed and simulated in Proteus, featuring 16-byte RAM, an add/subtract ALU, manual/automatic clocking, a 4-bit multiplier, Double Dabble BCD conversion, and negative-result display. Developed by Team Silicon 6 for IUT’s Digital Electronics Lab (EEE 4308).
